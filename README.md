## 🚀 Local Development

Clone the repository:

```bash
git clone https://github.com/Guru-CodesAI/Guru.git
```

Navigate into the project:

```bash
cd Guru
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start production server:

```bash
npm start
```
